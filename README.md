# MiniAula

Plataforma de cursos en línea con avance secuencial — Proyecto final de Ingeniería Web 2.

- `api/` — API REST (Node 20, Express 5, Sequelize, PostgreSQL 16)
- `web/` — SPA (React, Vite, Tailwind CSS)

Reglas de desarrollo: [REGLAS.md](REGLAS.md).

## Inicio rápido

```bash
cp .env.example .env
docker compose up --build
```

- API: http://localhost:3000/api/health
- Documentación: http://localhost:3000/api/docs
